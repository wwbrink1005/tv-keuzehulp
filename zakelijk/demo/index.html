Zo staat hij op de site van een winkel

Hieronder draait de keuzehulp precies zoals een webshop hem krijgt: in de eigen huisstijl, met alleen het eigen assortiment, en elke knop naar de eigen productpagina. Doorloop hem gerust helemaal.

Zo kan hij op jouw site staan:
demo-witgoed.nl/koelkasten

Jouw eigen inhoud

Tekst, foto's of reviews van de winkel zelf, bijvoorbeeld een uitleg over koelkasten.

Breedte van het vak 700 px
Bekijk de code die een winkel plakt

Twee stukjes, meer niet: de keuzehulp zelf en een klein script waarmee hij meegroeit met zijn inhoud. Waar en hoe breed hij staat, bepaalt de winkel zelf: over de volle breedte, in een kolom of achter een knop. Boven ongeveer 900 px staat de vraag naast de keuken, daaronder eronder.

<iframe id="keuzehulp" src="https://producthulp.nl/embed/koelkast/?klant=jouwwinkel"
        title="Koelkast keuzehulp" style="width:100%;height:760px;border:0"></iframe>
<script>
  window.addEventListener("message", function (e) {
    var f = document.getElementById("keuzehulp");
    if (e.source === f.contentWindow && e.data && e.data.type === "producthulp-keuzehulp-hoogte") {
      f.style.height = Math.max(560, e.data.hoogte) + "px";
    }
  });
</script>

Demo Witgoed is een fictieve webshop die we hebben gemaakt om te laten zien hoe de keuzehulp bij een winkel werkt. De koelkasten bestaan echt, de winkel en zijn productpagina's niet.
