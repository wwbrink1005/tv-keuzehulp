Vraag uitleg

Waar ga je je desktop voor gebruiken?

Waarom deze vraag?

Het doel van je desktop bepaalt welke grafische kaart, hoeveel RAM en welk type processor je nodig hebt. Dagelijks gebruik vraagt een efficiënte machine zonder GPU. Gaming en creatief werk vereisen een krachtigere grafische kaart. Je kunt maximaal 2 doelen aanvinken.

Welk type behuizing wil je?

Waarom deze vraag?

Het type behuizing bepaalt de grootte, uitbreidbaarheid en stroomverbruik van je desktop. Een tower is uitbreidbaar en krachtig maar neemt meer ruimte in. Een mini-pc is compact en energiezuinig, ideaal als je weinig ruimte hebt. Een all-in-one combineert pc en monitor in één apparaat. Kies 'Maakt niet uit' als je geen voorkeur hebt.

Hoe intensief ga je je desktop gebruiken?

Waarom deze vraag?

Licht gebruik zoals mailen en surfen vraagt weinig rekenkracht. Intensief gebruik zoals 4K gaming, videorendering of 3D-modellering vereist een krachtige grafische kaart en meer werkgeheugen. Hoe zwaarder je de desktop gebruikt, hoe belangrijker een sterke GPU is.

Hoeveel opslagruimte heb je nodig?

Waarom deze vraag?

Opslag bepaalt hoeveel bestanden, games en programma's je lokaal kunt bewaren. Gebruik je veel cloudopslag? Dan is 512 GB voldoende. Heb je veel games, films of grote projecten? Kies dan voor 1 TB of meer. Professionele gebruikers met grote bestanden hebben minstens 2 TB nodig.

Wat is nog meer belangrijk voor jou?

Waarom deze vraag?

Hier geef je extra wensen aan. Wi-Fi is handig als je geen vaste kabelverbinding wilt. RGB-verlichting geeft je setup een stijlvolle uitstraling. Waterkoeling zorgt voor lagere temperaturen bij intensief gebruik. Meerdere aansluitingen is handig als je extra monitoren of apparaten aansluit.
