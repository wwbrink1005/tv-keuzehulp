Vraag uitleg

Wat voor koffiemachine zoek je?

Waarom deze vraag?

Het type koffiemachine bepaalt het meest hoeveel je kwijt bent: een volautomaat (bonen, alles op 1 druk op de knop) kost gemiddeld een stuk meer dan een filterapparaat of capsulemachine. Een halfautomaat/handmatige machine geeft je zelf meer controle over je espresso, maar vraagt ook meer handigheid.

Hoeveel koffie heb je per keer nodig?

Waarom deze vraag?

De inhoud van het waterreservoir bepaalt hoe vaak je moet bijvullen. Voor 1-2 personen is een compact reservoir prima; voor een groot huishouden of veel bezoek is een groter reservoir handiger, zodat je niet steeds hoeft bij te vullen.

Wil je ook cappuccino of latte kunnen maken?

Waarom deze vraag?

Sommige machines schuimen melk automatisch op, andere hebben een handmatige stoompijp waarmee je het zelf doet. Wil je alleen zwarte koffie, dan hoeft je machine geen melksysteem te hebben.

Nog iets belangrijk?

Waarom deze vraag?

Touchbediening maakt bediening overzichtelijker, wifi laat je de machine op afstand bedienen via een app, automatisch ontkalken bespaart onderhoud, en niet elke machine kan ook thee zetten. Je kunt meerdere opties aanvinken.
