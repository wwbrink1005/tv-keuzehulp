Gaming laptop kopen: waar moet je op letten?

Bij een gaming laptop draait het niet om dezelfde specs als een gewone laptop. De videokaart bepaalt grotendeels hoe soepel je games draaien, en moet goed samenwerken met de rest van de laptop. We zetten de belangrijkste punten op een rij.

De videokaart is verreweg het belangrijkst

De videokaart (GPU) bepaalt grotendeels hoe soepel en mooi games draaien. In onze catalogus van 1708 laptops heeft 22,9% een dedicated videokaart (zoals een NVIDIA GeForce RTX) — de rest heeft alleen een geïntegreerde GPU, die voor lichte of oudere games volstaat maar bij nieuwere, zwaardere titels al snel tekortschiet. Modellen met een dedicated videokaart beginnen in onze catalogus vanaf ongeveer €335, met een mediaanprijs van €1899.

Vuistregel: hoe mooier en zwaarder de games die je wilt spelen, hoe krachtiger de videokaart moet zijn. Voor de meeste populaire games is een instap-RTX-kaart al voldoende; voor de nieuwste, grafisch zware titels op hoge instellingen heb je een stuk meer videokaartvermogen nodig.

Processor en videokaart moeten bij elkaar passen

Een krachtige videokaart heeft een processor nodig die het bijbeent, anders wordt de GPU geremd door de processor (een "CPU-bottleneck"). Voor de meeste games volstaat een middenklasse processor; voor de zwaarste, nieuwste games heb je een sterkere processor nodig om de videokaart optimaal te benutten.

Scherm: let op de verversingssnelheid

Naast de interne specs is het scherm minstens zo belangrijk. Een hogere verversingssnelheid (Hz) zorgt voor een merkbaar soepelere beeldervaring tijdens het gamen, vooral bij snelle games. Een standaardscherm op 60Hz voelt merkbaar minder vloeiend aan dan een gamingscherm met een hogere verversingssnelheid.

RAM: 16GB is voor de meeste games voldoende

Voor vrijwel alle games is 16GB RAM ruim voldoende. Alleen als je tijdens het gamen ook wilt streamen, opnemen of zwaar wilt multitasken, is 32GB de moeite waard.

Kort samengevat

  • Videokaart is het belangrijkste: 22,9% van onze catalogus heeft een dedicated GPU, vanaf €335
  • Processor moet krachtig genoeg zijn om de videokaart niet te remmen
  • Hogere verversingssnelheid van het scherm voelt merkbaar soepeler aan tijdens het gamen
  • 16GB RAM is voor de meeste games voldoende, 32GB alleen bij streamen/multitasken
